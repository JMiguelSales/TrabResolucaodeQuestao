# TrabResolucaodeQuestao
Esse programa, criado em 2022, foi um projeto de 2 semanas com o intuito de criar um aplicativo de resolução de questões. Nesse app, o usuário pode inserir questões, criar repositórios e solucionar as questões adicionadas, além de, ter seu desempenho salvo. Esse programa utiliza arquivos de texto para armazenar todas as informações.
